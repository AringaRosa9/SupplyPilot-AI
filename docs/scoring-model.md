# Hotel / Flight 评分模型设计

> 状态：Approved for M0（2026-08-11）
> 初始模型：`hotel-v1`、`flight-v1`

## 1. 流水线

```text
硬性规则 → 特征校验 → 0–100 标准化 → 加权求和 → 等级映射 → 置信度 → 建议
```

输入使用 Product 数据版本与计算时快照。结果保存模型版本、规则版本、维度原值/标准化值/权重/贡献、缺失字段和计算时间，确保可复现。

## 2. 硬性入池规则

通用规则：供应商为 `active/watchlist`；商品标识唯一；市场和活动范围匹配；币种、价格为有效值；销售/出行区间与活动相交；库存更新时间未超过配置时效。

Hotel 必须满足：酒店名、目的地、星级、入住/离店区间、房型、每晚含税价、可售间夜；星级和客群硬门槛来自活动需求。Flight 必须满足：出发地、目的地、航班号或产品编码、起降时间、含税价、可售座位；航线必须在活动目标范围内。

硬规则失败不产生 0 分评级，而返回结构化拒绝：`rule_code`、字段、实际值、期望值、可否修复。

## 3. 维度与权重

| Hotel 维度 | 权重 | 核心输入 |
|---|---:|---|
| price_competitiveness | 30% | 相对竞品价格优势、活动折扣 |
| historical_performance | 20% | 历史销量、转化率（同市场/星级基准） |
| inventory_stability | 20% | 可售间夜、更新频率、波动与售罄率 |
| service_quality | 15% | 住客评分、履约/投诉表现 |
| segment_fit | 10% | 活动客群与设施/标签匹配 |
| supplier_quality | 5% | 履约率、取消率、响应时效 |

| Flight 维度 | 权重 | 核心输入 |
|---|---:|---|
| route_value | 25% | 目标航线缺口、直飞与时刻覆盖 |
| discount_depth | 25% | 相对基准含税价和折扣 |
| sellable_inventory | 20% | 可售座位、日期覆盖和稳定性 |
| schedule_quality | 15% | 起降时段、经停、总时长 |
| historical_performance | 10% | 点击/预订转化和退改表现 |
| supplier_quality | 5% | 履约率、取消率、响应时效 |

连续特征默认按同活动、市场、产线的 winsorized P5–P95 min-max 标准化；冷启动使用经批准的业务锚点。负向指标反转。布尔/枚举映射必须保存在模型配置中，不写死于 UI。

## 4. 分数、等级和上架建议

`score = Σ(normalized_dimension_score × weight)`，四舍五入到 1 位小数。

- S：`score ≥ 90`；A：`80–89.9`；B：`65–79.9`；C：`<65`。
- 建议上架：硬规则通过、`score ≥ 80`、`confidence ≥ 0.75` 且无阻塞风险。
- 分数相同按置信度、活动缺口贡献、库存量、稳定 product id 排序。

## 5. 缺失数据与置信度

缺失必填或硬规则输入时停止评分。非关键特征缺失时，以可用特征重新归一维度，但不能把缺失填成行业均值后伪装为真实值。

```text
coverage = Σ(available_feature_weight)
freshness = 输入时效得分的加权均值
sample_reliability = 历史样本量映射到 0–1
confidence = clamp(0.60×coverage + 0.25×freshness + 0.15×sample_reliability, 0, 1)
```

`confidence < 0.75` 标为低置信度，UI 优先展示 `missing_fields` 和补充建议；`<0.5` 不给自动上架建议。

## 6. 版本与失效

模型配置包含 `product_line`、`version`、权重、阈值、标准化参数、硬规则版本、生效时间和状态。发布后不可原地修改。Product 的价格、库存、日期、市场/航线、服务质量、供应商或活动适配字段变化会使当前评级失效，并通过幂等任务重评。旧结果永久保留。

## 7. 测试基线

- 每条硬规则包含通过/边界/失败样例。
- 权重和必须精确为 1；维度分与总分限定 0–100。
- 缺失、过期与样本不足会单调降低置信度。
- 固定 Hotel/Flight 金丝雀样本记录期望等级、贡献排序和置信度范围。
